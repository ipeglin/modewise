# Wavelet multiresolution analysis

`modwt_mra` splits each channel into octave bands with the maximal overlap discrete wavelet transform (MODWT): details D₁…D_J and a smooth S_J. They add up to the signal, so they work like any other decomposition in modewise (Hilbert spectra, connectivity per mode, epochs).

```python
import numpy as np
import modewise

fs = 1.25
x = np.random.default_rng(0).standard_normal((2, 488)).cumsum(axis=1)   # a drifting series
mra = modewise.modwt_mra(x, fs, levels=5, boundary="reflection")
print(mra.n_modes, mra.centre_frequencies_hz.round(3))      # S5, D5, …, D1 from low to high
assert np.allclose(mra.modes.sum(axis=0), x)
```

## Choices and sources

| Choice | Sources | Strength |
|---|---|---|
| MODWT (undecimated, filters divided by √2, stride 2^{j−1} at level j) and its MRA: each detail is synthesised from one level's coefficients | Percival & Walden (2000), ch. 5; Percival & Mofjeld (1997); MATLAB `modwt`/`modwtmra`; PyWavelets `mra(transform="swt")` | consensus |
| Not the decimated DWT MRA | Percival & Walden (2000): the DWT MRA depends on where the series starts and needs special lengths; the MODWT is shift-invariant and works for any length | consensus. Rejected. |
| Wavelet filter h_l = (−1)^l g_{L−1−l} from the scaling filter g | Percival & Walden (2000); PyWavelets `rec_hi` (checked for every filter) | consensus |
| Periodic boundary by default | the MODWT's definition; MATLAB and PyWavelets defaults | consensus |
| `boundary = "reflection"`: transform the series followed by its reverse, keep the first n samples | Percival & Walden (2000); MATLAB `modwt(..., 'reflection')` | consensus. Use it for series that are not periodic, such as BOLD runs with a drift: the periodic boundary joins the last sample to the first. |
| Default wavelet `sym4` (LA(8) in Percival & Walden) | MATLAB `modwt` default; Percival & Walden's usual choice | consensus. PyWavelets has no default. |
| Default depth: the deepest J whose equivalent filter, (2^J − 1)(L − 1) + 1 samples, fits the series; at most ⌊log₂ n⌋ | Percival & Walden (2000) | single source for the default; MATLAB uses ⌊log₂ n⌋, which lets filters wrap the series several times |
| Filters: haar, db1–db10, sym2–sym10, coif1–coif5 | PyWavelets tables (MIT; notice in `THIRD_PARTY_NOTICES.md`), generated by `methods/wavelet/filters/generate.py` | the symlet tables are accurate to about 5e-12 |

## Output layout

Mode 0 is S_J, then D_J, …, D₁, so modes go from low to high frequency as in every modewise decomposition. D_j covers roughly [fs/2^{j+1}, fs/2^j]: at a TR of 0.8 s (1.25 Hz), D₁ is 0.31–0.63 Hz, D₃ 0.08–0.16 Hz and D₅ 0.02–0.04 Hz. Every channel uses the same filter bank, so modes are aligned across channels. The centre frequency is the power-weighted spectral centroid pooled over channels, as for EMD and MEMD.
